# MaJeLeD: Kariri (Kipeá and Dzubukuá)

The Kipeá (554 rows) and Dzubukuá
(529 rows; doculect label `dzobukua`)
entries of MaJeLeD (Gerardi and Tresoldi 2024, CC BY 4.0, doi:10.5281/zenodo.12304366;
macro-je.tsv sha256 98f20307b47429818edbd06157d3fe9ba1c949a1443c56e22b112429bb86ce21).

`Value` is MaJeLeD's VALUE (the historical spelling with accents); each
comma-separated alternative becomes one `Form`. MaJeLeD's FORM column drops the
accents and its TOKENS are partial, so neither is used: `Segments` is empty and
the rows are written-only evidence. Kipeá and Dzubukuá stay separate varieties.
Concept mappings are MaJeLeD's Concepticon IDs where present in Arca's frozen table.
