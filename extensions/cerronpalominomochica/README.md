# Cerrón-Palomino 1995 Mochica wordlist (CLDF edition)

All 208 forms of https://github.com/pano-takanan-history/cerronpalominomochica
(commit ccbab02, CC BY 4.0; forms.csv sha256 180f3bb7d28710e7ad0f9ec358f5d734eccfe7c88af5cb4161a510ee0c61a9a7): colonial Mochica in
Cerrón-Palomino's normalized orthography, glossed in Spanish.

`Segments` is left empty here. The CLDF edition's segments come from an
orthography profile over Cerrón-Palomino's normalized spelling; Arca uses that
mapping as a reviewed, variety-scoped orthographic profile
(`varieties/moc-mochica/custom/profile.tsv`), so the readings are labelled
profile-derived, not source-supplied. Concepticon mappings are those of the CLDF
edition, kept where the ID exists in Arca's frozen Concepticon table.
