## Borba's spelling notes (copied from the source)

p. 72: "… pelo menos na lingoa *Chavante* existem o *l*, o *r* forte e um *z* como o *th* inglez … Nesta, o *r* forte é muito guttural, o *J*, sôa como no hespanhol e o *th* como no inglez."

Table footnotes, p. 73: "(2) O *J* sôa como no hespanhol." (on *Jaque*) — "(3) O *th* sôa como no inglez." (on *Othigue*). Footnote (1) concerns the Guarani column only.

So: `r` (word-initial/strong, `rr`) = a very guttural r; `j` = Spanish jota; `th` = English th. All other letters follow Portuguese orthography of the time. This is a spelling, not a phonetic transcription.

## Conventions

* `Value` = the full printed Chavante entry, including Borba's footnote markers "(2)", "(3)". `Form` = one form without footnote markers. Entries with two printed alternatives ("Acli. Athlï", "Antla, Inthla", "Tócle, Tothle", "Dejuáca, Tofoaca") give one row per alternative with the same `Value`.
* Forms are printed with an initial capital throughout; capitalisation is kept as printed.
* `Segments` is empty. Parameter `Name` = Portuguese gloss as printed | English translation. Imperatives ("Deite fora", "Levante-se", "Sente-se", "Venha"), "Dia", "Muito", "Velho", "Páo", "Terra", "Campo" and specific animals/plants without an exact Concepticon concept are left unmapped.
* `Loan` = true only for *Guiacú* 'jacú' (transparently the Portuguese/Tupi gloss word). *Hon* 'preto' is identical to the Cayguá form in the same row; noted in `Comment`, not marked.

## Identity

Borba's "Chavante" = **Oti** (otii1244), the extinct São Paulo Chavantes between the Paranapanema, Peixe and Pardo rivers. They are *not* the Akwẽ Xavante (Jê) and *not* the Ofayé "Chavantes de Matto Grosso". Quadros 1892 (dataset `quadros1892`) is an independent record of the same language; von Ihering 1907 (Revista do Museu Paulista 7: 228–231) reprints both lists in normalised form and was used only as a finding aid, never as a reading.
