# ASJP v21.1: selected South American isolate lists

Rows of the Lexibank CLDF edition of the ASJP Database v21.1 (CC BY 4.0,
https://github.com/lexibank/asjp, forms.csv sha256 4ee30b771a2cba59e7e904587f7f60dc3d823824a7b9aae9dd6f73a960139321),
restricted to three lists for which Arca has no better transcribable source:

| ASJP list | Arca language | Glottocode | Forms | Original source cited by ASJP |
|---|---|---|---:|---|
| PUQUINA | Puquina | puqu1242 | 39 | ASJP source 8787 |
| BETOI | Betoi | beto1237 | 21 | ASJP source 1144 |
| TARUMA | Taruma | taru1236 | 16 | ASJP source 10264 |

ASJP gives no Glottocode for BETOI; Arca assigns the Glottolog dialect code
beto1237. ASJP's CUICA list is not used: it is Jahn's (1927) Timote vocabulary with
the noun prefixes removed, which Arca takes from Jahn directly (`jahn1927`). `Value`/`Form` are in ASJPcode;
`Segments` is Lexibank's conversion of ASJPcode, a reduced phonetic alphabet,
not a specialist transcription (the same limitation as GLED, which derives from
ASJP). The PUQUINA list includes Quechua/Aymara loans flagged by ASJP.
These lists are placeholders until original sources are transcribed.
